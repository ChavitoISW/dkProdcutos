# DK Productos - Página Web Estática

Sitio web profesional para DK Productos, un servicio de personal shopper.

## 🌟 Características

- **Diseño Responsivo**: Se adapta perfectamente a cualquier dispositivo (móvil, tablet, desktop)
- **Navegación Suave**: Transiciones y animaciones fluidas
- **Secciones Completas**:
  - Hero con llamada a la acción
  - Información sobre el servicio
  - Servicios detallados
  - Proceso paso a paso
  - Testimonios de clientes
  - Formulario de contacto
- **Diseño Moderno**: Paleta de colores elegante y profesional
- **Optimizado para SEO**: Meta tags y estructura HTML semántica

## 📁 Estructura de Archivos

```
dkProductos/
├── index.html      # Página principal
├── styles.css      # Estilos CSS
├── script.js       # JavaScript para interactividad
└── README.md       # Este archivo
```

## 🚀 Cómo Usar

1. Abre el archivo `index.html` en tu navegador web
2. Para desarrollo local, puedes usar cualquier servidor local como:
   - Live Server (extensión de VS Code)
   - Python: `python -m http.server 8000`
   - Node.js: `npx serve`

## 🎨 Personalización

### Colores
Los colores principales se definen en `styles.css` en las variables CSS:
- `--primary-color`: #d4a574 (Dorado)
- `--secondary-color`: #8b6f66 (Marrón)
- `--dark-color`: #2c2c2c (Negro)
- `--light-color`: #f8f5f2 (Beige claro)

### Contenido
Puedes modificar el contenido directamente en `index.html`:
- Testimonios de clientes
- Servicios ofrecidos
- Información de contacto
- Textos descriptivos

### Fuentes
El sitio usa fuentes de Google Fonts:
- Montserrat (texto general)
- Playfair Display (títulos)
